# Serenity-Grace

Serenity-Grace 是一款面向 Halo 2.x 的个人博客主题，强调清晰的内容层级、稳定的页面切换和细致的交互反馈。主题支持亮色与暗色模式，并提供完整的个人主页、文章、友链和项目展示页面。

## 特性

- 亮色与暗色主题模式，可跟随系统或手动切换
- 响应式布局，适配桌面、平板和移动设备
- 首页 Hero、风向标导航、近期文章、站点动态和天气时钟
- 文章封面、目录、阅读进度、相关文章、版权和分享组件
- 关于页面的个人信息、技能、经历和自定义内容模块
- 友链卡片、分组筛选、搜索和友链申请功能
- 项目集支持 GitHub 项目信息、版本发布和自定义项目
- 项目支持“项目展示”和“跳转链接”两种打开方式
- 图片库、碎碎念、留言板、便签墙、装备和星图库页面
- 基于 PJAX 的页面切换和 IntersectionObserver 入场动画
- 支持自定义导航图标、分类图标、主题颜色和页面文案

## 视觉与交互

| 项目 | 描述 |
| --- | --- |
| 亮色与暗色模式 | 支持跟随系统偏好或手动切换，切换时使用平滑的颜色过渡，减少页面闪烁。 |
| 主题色配置 | 可在后台分别配置亮色和暗色主题色，按钮、链接、边框和装饰会统一使用主题变量。 |
| 响应式布局 | 采用响应式栅格和弹性布局，桌面、平板与手机使用合适的间距、字号和卡片排列。 |
| 页面滚动反馈 | 首页背景会随滚动位置渐进调整模糊和透明度，内容保持清晰；文章页面提供阅读进度反馈。 |
| 页面过渡 | 使用 PJAX 保留全局状态并减少重复刷新，页面进入和离开保持连续的过渡效果。 |
| 入场动画 | 标题、区块和卡片在进入视口后分层显示，动态内容加载完成后再触发动画，避免首屏同时跳动。 |
| 卡片交互 | 文章、友链和项目卡片提供轻微位移、阴影和边框反馈，搜索、筛选、随机访问等操作即时响应。 |
| 项目打开方式 | 项目卡片支持版本展示和直接跳转两种模式，可按项目配置选择。 |
| 指针样式 | 支持自定义指针和交互状态反馈，按钮、链接及可拖拽元素具有明确的悬停和按下状态。 |
| 动画可访问性 | 遵循 `prefers-reduced-motion` 用户偏好，动画用于表达层级和状态，不依赖颜色单独传达信息。 |

## 安装

### 手动安装

1. 从 Releases 下载最新主题压缩包。
2. 在 Halo 控制台进入“外观 > 主题”，上传压缩包。
3. 启用主题，并进入“主题设置”完成个性化配置。

### 开发部署

在主题目录的上级目录执行 `deploy.bat`，脚本会构建主题、更新发布目录并推送到 GitHub。执行前请确认已安装 Python、Git，并已配置 GitHub 仓库访问权限。

## 配置重点

所有选项均可在 Halo 控制台的主题设置中完成：

- 基本信息：站点标题、作者、描述、Logo、Favicon 和默认主题模式
- 导航图标：内置页面图标和自定义页面图标
- 首页内容：背景、装饰、个人简介、文章、动态、随想和生活回想
- 社交链接：GitHub、邮件及其他社交平台链接
- 项目展示：GitHub Token、项目列表、自定义项目、归属、分类和打开方式
- 友链页面：站点信息、友链展示模式和申请配置
- 页脚与 SEO：备案信息、运行时间、RSS、关键词和结构化数据

### 项目打开方式

项目列表中的“项目打开方式”有两个选项：

- `项目展示`：GitHub 项目请求仓库信息，点击卡片打开版本详情。
- `跳转链接`：直接打开配置的 URL，不请求 GitHub API。适合网站、演示地址和非 GitHub 项目。

“项目归属”只用于统计“我的项目”和“收藏项目”，“项目分类”只用于前台分组。旧配置未设置打开方式时，默认使用“项目展示”。

## 插件依赖

主题的部分页面需要 Halo 应用市场中的插件提供数据：

| 插件 | 用途 |
| --- | --- |
| 评论组件 | 文章评论和留言板 |
| 瞬间 | 碎碎念页面数据 |
| 链接管理 | 朋友们页面数据 |
| 图库管理 | 图库页面数据 |

可选插件包括 AstraHub 星链、朋友圈、爱发电、LightGallery、便签墙和 Steam 数据组件。
